WebToAgent

Let web-based AI read local files and direct a local coding agent.

Installation

Load the extension in Chrome: open chrome://extensions, enable Developer mode, click "Load unpacked", and select the extension folder.
(Optional) Install the native service: double-click 安装本地服务.bat in the project root and paste the extension ID when prompted.
Restart Chrome and open any supported AI site.

Usage

A 📁 button appears in the bottom-right corner of the page (shortcut: Ctrl+Shift+F):

File treeClick 📁 to open the sidebar, browse folders, and click a file to insert it into the chat box.
@ commandType @filename or @folder in the chat box, then select an item from the suggestions.

Two modes

Native service mode (recommended): works automatically after installation. Requires Node.js.

Browser mode: requires no installation. Open the sidebar and click "Choose folder" to grant access.

Supported sites

  • Qwen (chat.qwen.ai)
  • ChatGPT (chatgpt.com)
  • Google AI Studio (aistudio.google.com)
  • Gemini (gemini.google.com)
  • Claude (claude.ai)

Shortcuts

  • Ctrl+Shift+F — Open or close the file panel
  • @ — Start a file search in the chat box
  • ↑ ↓ — Move through search results
  • Enter or Tab — Select a file
  • Esc — Close search

Uninstall

Extension: remove it from chrome://extensions.

Native service: double-click 卸载本地服务.bat.
